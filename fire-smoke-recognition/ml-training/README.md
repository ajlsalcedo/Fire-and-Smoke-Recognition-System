# Machine-learning workspace

Keep dataset preparation, model training, evaluation, and model export separate.

- `dataset-preparation/`: dataset source notes, label mapping, preprocessing, and split instructions.
- `model-training/`: training scripts or notebooks.
- `evaluation/`: metrics, confusion matrices, error analysis, and experiment notes.
- `model-export/`: reproducible conversion/export instructions.

Dataset and model artifacts are intentionally not included yet. Record dataset licensing and provenance before use.
