# Requirements

Track functional and non-functional requirements here.

Initial functional requirements:
- Accept an image upload.
- Validate supported image input.
- Preprocess the image consistently with training.
- Classify as Fire, Smoke, or Neither when a trained model is available.
- Display the result and a safety disclaimer.

Initial non-functional requirements:
- Responsive interface.
- Clear errors for invalid input or model-loading failure.
- Documented model limitations and evaluation results.
